Цикл for

Цикл for в Python предназначен для перебора элементов любой коллекции (строка, список, кортеж, словарь, множество).

for переменная in последовательность:
    тело_цикла

Пример перебора строки:

word = "Python"
for char in word:
    print(char, end='-')
# Результат: P-y-t-h-o-n-

Функция range()

Функция range генерирует последовательность чисел. Она часто используется вместе с циклом for для выполнения действий определенное количество раз.

Варианты использования (перегрузки)

range(stop)
Генерирует числа от 0 до stop - 1.
for i in range(3):
    print(i, end=' ')
# Результат: 0 1 2
range(start, stop)
Генерирует числа от start до stop - 1.
for i in range(2, 5):
    print(i, end=' ')
# Результат: 2 3 4
range(start, stop, step)
Генерирует числа от start до stop - 1 с шагом step.
for i in range(0, 10, 2):
    print(i, end=' ')
# Результат: 0 2 4 6 8

Обратный порядок (отсчет назад)

Чтобы считать в обратную сторону, нужно использовать отрицательный шаг. В этом случае start должен быть больше stop.

Пример обратного отсчета:

# От 5 до 1 (не включая 0)
for i in range(5, 0, -1):
    print(i, end=' ')
# Результат: 5 4 3 2 1

Цикл while

Цикл while выполняется до тех пор, пока истинно заданное условие (логическое выражение).

while логическое_выражение:
    тело_цикла

Важно: Если внутри цикла не меняется никакая переменная из логического выражения, то цикл никогда не закончится (бесконечный цикл).

Пример:

count = 3
while count > 0:
    print(f"Осталось: {count}")
    count -= 1  # Уменьшаем счетчик, чтобы условие когда-то стало False
# Результат:
# Осталось: 3
# Осталось: 2
# Осталось: 1

Операторы break и continue

Эти операторы позволяют изменить стандартное поведение циклов.

Оператор Описание
break Полностью прерывает выполнение цикла. Программа переходит к инструкциям после цикла.
continue Прерывает текущую итерацию и переходит к следующей (возвращается к началу цикла/проверке условия).

Пример использования:

for i in range(10):
    if i == 3:
        continue  # Пропускаем число 3
    if i == 6:
        break     # Завершаем цикл на числе 6
    print(i, end=' ')
    
# Результат: 0 1 2 4 5

Блок else в циклах

В Python циклы for и while могут иметь необязательный блок else.

Код в блоке else выполняется только в том случае, если цикл завершился "естественным" образом (условие стало ложным или закончился диапазон).

Если выход из цикла произошел с помощью break, блок else НЕ выполняется.

for item in collection:
    if item == target:
        break
else:
    # Выполнится, если break НЕ сработал (элемент не найден)
    print("Элемент не найден")

Пример (поиск простого числа):

number = 15
# Проверяем, есть ли делители
for i in range(2, number):
    if number % i == 0:
        print(f"{number} - составное число (делится на {i})")
        break
else:
    print(f"{number} - простое число")
